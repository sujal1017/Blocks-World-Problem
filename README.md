# Blocks World Problem Simulation

## Artificial Intelligence Mini Project

A visually interactive web-based simulation of the classical **Blocks World Problem** in Artificial Intelligence.

This project demonstrates how a robot arm rearranges blocks from an initial configuration into a desired goal configuration by following AI planning rules and constraints.

---

# Project Overview

The Blocks World Problem is a classical AI planning problem used to study:

- Problem Solving
- State Space Search
- Goal-Based Planning
- Automated Reasoning
- Robotics Manipulation

This project provides a complete animated visualization of the Blocks World Problem using:

- HTML
- CSS
- JavaScript

without any external frameworks.

# Blocks World Rules

1. Only one block can be moved at a time.
2. Only clear blocks can be moved.
3. Blocks can be placed:
   - on the table/floor
   - or on another clear block.
4. The robot arm can hold only one block at a time.

# Working of the Simulation

## Step 1 — Initial State

Blocks are shown in the initial configuration.

---

## Step 2 — Unstacking

The robot arm removes blocks one by one from the top.

---

## Step 3 — Floor Placement

Blocks are placed separately on the floor/table.

---

## Step 4 — Goal Stack Construction

Blocks are rearranged and stacked again in the required order.

---

## Step 5 — Goal State Achieved

Final goal configuration is displayed successfully.
