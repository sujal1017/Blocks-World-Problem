1. What is the Blocks World Problem?

The Blocks World is one of the most famous planning domains in Artificial Intelligence history. It consists of a set of square blocks stacked on a table. The goal is to transform a given initial configuration of blocks into a targeted goal layout using a mechanical robot arm.

2. AI Planning Concepts

This simulation visualizes Classical AI Planning frameworks (STRIPS/PDDL). It deals with finding a sequence of valid atomic actions that transitions the environment from an Initial State to a Goal State through state-space search mechanics.

3. Operational Domain Rules

  • Only one block can be held/moved by the robot manipulator arm at any moment.
  • A block can only be moved if its top surface is Clear (no block rests on top of it).
  • Blocks can be dynamically placed directly onto the flat table surface or stacked cleanly on top of another clear block.
